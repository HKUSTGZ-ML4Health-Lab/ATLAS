# Blinded Clinician Evaluation

This appendix contains preparation, aggregation, validation, and paper-output
code for the completed ATLAS-versus-Gemini clinician evaluation.

## Design

- 40 cases: 20 Western and 20 GeriMedBench cases.
- 3 clinicians.
- ATLAS versus Gemini 3.1 Pro Preview.
- Independent case order and A/B mapping for each reviewer.
- Five 1--5 rating criteria.
- Case-level safety and preference judgments.

Run:

```bash
bash CODE_APPENDIX/reproduce_BLINDED_CLINICIAN_EVALUATION.sh
```
